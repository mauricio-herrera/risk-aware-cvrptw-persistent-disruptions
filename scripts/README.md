# Reproducibility scripts

## `make_trip_revision_figures_v3.py`

Generates the six canonical main figures using the frozen V3 publication style.

## `make_trip_supplementary_figures.py`

Generates Supplementary Figures S1--S6 using the same visual conventions as
the canonical V3 main figures.

## `audit_frozen_results.py`

Checks the principal numerical and structural invariants used by the revised
manuscript and supplementary material.

The figure scripts should be interpreted together with the source tables under
`figure_data/` and the complete confirmatory evidence under `frozen_outputs/`.

Development-stage scripts, pilot implementations, smoke tests, and superseded
legacy analyses are intentionally excluded from this archival release.
